# Conversaciones demostrativas

## Pedido con contexto
Cliente: Quiero una hawaiana.
PizzaBot: ¿Qué tamaño prefieres para Hawaiana: chica, mediana o grande?
Cliente: Grande.
PizzaBot: Agregué 1 Hawaiana tamaño grande. ¿Deseas agregar alguna bebida o revisar tu pedido?
Cliente: Dos refrescos.
PizzaBot: Agregué 2 × Refresco. ¿Deseas algo más?
Cliente: Confirmar pedido.
PizzaBot: ¿Tu pedido será para recoger o para entrega a domicilio?
Cliente: Recoger.
PizzaBot: [Resumen] Escribe 'confirmar pedido' para finalizar.
Cliente: Confirmar pedido.
PizzaBot: Pedido de demostración confirmado.
